About me

I'm a mobile developer with 9+ years of experience building Android and cross-platform apps in React Native, Expo, TypeScript and Kotlin. Today I work at Spartakus (Laurentide Controls, an Emerson Impact Partner), building an offline-first React Native app that industrial field technicians use with FLIR thermal cameras. On my own time I built and launched Petnubo, a bilingual pet-community platform whose app is live on the App Store, with Spring Boot services and AI content agents.

I use AI coding agents (Claude Code and Codex) every day, and I review and test every change they make. I pick up new tools quickly and enjoy hard problems. Away from the keyboard you'll usually find me hiking or at the movies.

Notable Projects

Petnubo (personal project, built solo)

A bilingual (English/French) home for animal lovers: articles, short videos, a social feed, private messages, missing-pet alerts with maps, fundraisers and a shop. I designed, built and run all of it.

  • Mobile app live on the App Store (Android in Google Play closed testing): Expo, React Native, TypeScript, TanStack Query, Drizzle/SQLite, plus a Kotlin native module that compresses video on the phone's hardware encoder (Media3).
  • Backend: two Java 21 / Spring Boot microservices, each with its own PostgreSQL database, JWT with rotating refresh tokens, encrypted messaging, S3 media and an ffmpeg video worker.
  • Web: a Next.js / React 19 site and admin portal for moderation, appeals and analytics.
  • AI agents: a Python article agent uses the Claude and OpenAI APIs with web search to draft cited articles for human review, and a video agent finds free clips.
  • Delivery: Docker Compose, Cloudflare Tunnel, GitHub Actions CI and Sentry, with development done through Claude Code and Codex under strict review rules.
